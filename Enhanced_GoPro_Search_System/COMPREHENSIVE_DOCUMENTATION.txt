📊 SYSTEM ARCHITECTURE:

┌─────────────────────────────────────────────────────────────────────────────┐
│                        ENHANCED SEARCH FLOW                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. USER QUERY INPUT                                                         │
│    ↓                                                                        │
│ 2. GEMINI KEYWORD EXTRACTION                                                │
│    • Primary Keywords (must-have): activities, objects                     │
│    • Context Tags (nice-to-have): scenes, locations                        │
│    • Stop Word Filtering: removes "the", "video", "me", "get", etc.        │
│    ↓                                                                        │
│ 3. MULTIPLE CONDITION DETECTION                                             │
│    • Detects "and" patterns: "track and snow" → 2 conditions               │
│    • Parallel processing with dual API keys                                │
│    ↓                                                                        │
│ 4. SYNONYM EXPANSION                                                        │
│    • Activity synonyms: "cycling" → ["mountain biking", "biking", "bike"]  │
│    • Scene synonyms: "track" → ["race track", "racetrack", "racing_track"] │
│    • Object synonyms: "car" → ["car", "race car", "racecar", "rally car"]  │
│    ↓                                                                        │
│ 5. PRIMARY KEYWORD FILTERING                                                │
│    • Filters 98 chunks → 15-25 relevant chunks                             │
│    • Mandatory matching on activity_tags, object_tags, scene_tags          │
│    ↓                                                                        │
│ 6. SEMANTIC RANKING                                                         │
│    • Text Embedding Similarity: 50%                                        │
│    • Description Overlap: 30%                                              │
│    • Context Relevance: 20%                                                │
│    ↓                                                                        │
│ 7. AI SUMMARY GENERATION                                                    │
│    • Parallel processing with dual API keys                                │
│    • Explains why each chunk was selected                                  │
│    ↓                                                                        │
│ 8. FORMATTED RESULTS                                                        │
│    • Video ID, chunk number, timing, scores, tags, AI summary              │
└─────────────────────────────────────────────────────────────────────────────┘
